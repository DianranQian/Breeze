# 内置中文字体

这个目录里的字体是**编辑器界面文字的渲染基础**。没有它，界面上所有汉字
都会显示成方框（`□□□`）。

## 文件

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `NotoSansSC-Subset.ttf` | ≈ 2.2 MB | Noto Sans SC Regular 的子集 |
| `OFL.txt` | 4.3 KB | SIL Open Font License 1.1 原文 |
| `重新生成子集.py` | — | 可复现地重建上面那个子集 |

## 来源与许可

| 项 | 值 |
| --- | --- |
| 上游字体 | Noto Sans SC（思源黑体简体中文版同源） |
| 上游仓库 | <https://github.com/notofonts/noto-cjk> |
| 上游文件 | `Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf`（可变字体） |
| 版本 | 本机 `C:\Windows\Fonts\NotoSansSC-VF.ttf`，16.95 MB |
| 许可证 | **SIL Open Font License 1.1**（允许再分发与修改，见 `OFL.txt`） |
| 处理 | 固定 `wght=400` 得到静态实例，再按字符集做子集 |

OFL 1.1 明确允许打包与再分发字体软件（包括子集形式），
要求是保留许可证原文、且不得单独售卖字体本身。
本目录下的 `OFL.txt` 满足前者；字体仅作为编辑器的一部分提供。

## 为什么用子集而不是完整字体

完整字体太大，而界面用不到那么多字：

| 方案 | 大小 | 覆盖 |
| --- | --- | --- |
| 完整可变字体 | 16.95 MB | 全部 |
| 静态实例（wght=400） | 10.11 MB | 全部 |
| 子集：CJK 基本区全集 | 7.34 MB | 全部常用汉字（U+4E00–U+9FFF） |
| **子集：本目录采用** | **2.25 MB** | GB2312 全集（6763 字）+ 源码用到的全部字符 + ASCII + 标点 |
| 子集：只含源码字符 | 0.32 MB | 只有界面自己写死的那 1079 个字 |

选 2.25 MB 这一档，而不是最小的 0.32 MB，原因很具体：

**实体名、场景名、日志里的文件路径都是用户输入的，字符不可预知。**
场景树是编辑器的核心面板，用户给它起名叫「勇者之剑」或「饕餮之森」
是再正常不过的事。如果只打包"源码里出现过的字"，
用户一打自己取的中文名就会看到方框 —— 那不是省了 2 MB，
而是把一个明显缺陷留在了最常用的面板上。

反过来，7.34 MB 的"全 CJK"档也确实超出了需要：
GB2312 的 6763 字覆盖现代汉语日常用字，多花的 5 MB 只为了
生僻字与异体字，性价比不高。

### 已知限制

GB2312 之外的生僻字（Unicode 扩展 A/B 区，多为罕见人名、地名用字）
**不在**子集内，输入这类字会显示方框。

如果确实需要，设置环境变量指向一个完整字体即可，无需改动代码：

```powershell
# 用完整字体作为后备（在子集字体之后追加）
$env:BEVY_STUDIO_FONT = "C:\Windows\Fonts\NotoSansSC-VF.ttf"
```

`.ttc` 字体集合需要用 `BEVY_STUDIO_FONT_INDEX` 指定字面序号。

## 维护：改动了界面中文文案怎么办

子集是按字符集生成的，因此**新增界面文案里若出现子集外的字，就会显示方框**。

这个问题由一条自动化测试守住：

```text
crates/editor_ui/src/fonts.rs :: 内置字体覆盖界面上出现的全部汉字
```

它会扫描 `crates/editor_ui/src/**/*.rs`，取出所有汉字，
逐个用 `epaint` 的 `has_glyphs` 检查是否存在于内置字体中。
一旦有人写下子集外的字，这条测试立刻失败并列出具体是哪些字。

修复方式就是重新生成子集：

```powershell
# 在仓库根目录执行
python crates/editor_ui/assets/fonts/重新生成子集.py
```

脚本会自行从源码收集字符、并集 GB2312、重新子集化，
然后覆盖 `NotoSansSC-Subset.ttf`。之后重跑测试即可。

## 重新生成脚本做了什么

1. 扫描 `crates/**/*.rs` 与 `README.md`，收集出现过的**全部**字符；
2. 并上 GB2312 的全部汉字（6763 个）与 ASCII、常用标点、
   CJK 标点、全角字符；
3. 用 `fontTools.varLib.instancer` 把可变字体固定到 `wght=400`；
4. 用 `pyftsubset` 按字符集裁剪，保留全部布局特性（字距、连字）。

依赖：`fonttools`（含 `pyftsubset`）。
