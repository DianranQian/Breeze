# 资源预览（R15）

> 目标：在资源浏览器里**单击**一个资源，右侧/下方立即显示这个资源的真实内容。
> 本文记录实际实现、真实支持的格式、能力边界、测试与验收证据。
> 能力成熟度见 [`engine_capability_map.md`](./engine_capability_map.md) 的 E1/E10。

## 1. 为什么做、原先缺什么

改造前的行为（真实调用链）：

```text
assets_panel::绘制文件行
  → 名称 Label（Sense::click_and_drag）
  → clicked() 没有任何分支      ← 单击被消费掉，什么也不发生
  → double_clicked() → 打开脚本 / 打开场景 / 从资源创建实体
  → context_menu → 试听 / 查找引用 / 加入场景 / 定位 / 重命名 / 删除
```

也就是说：

* **单击没有预览**，连"选中"这个概念都不存在（`界面状态` 里没有选中资源字段）；
* 面板里没有预览区域；
* `缩略图缓存`（`editor_app::plugin`）有类型、有查询入口，但**从未被填充**，
  图片行只能画一个 `🖼` 占位符；
* 资源列表只扫描 `assets/`，`scenes/` 下的场景文档根本不在列表里，
  因此"双击场景 → 打开场景"这条分支对真实项目永远不可达。

所以本轮不是"修一个断掉的调用"，而是**补齐一个从未建立的工作流**；
同时把两处既有缺口（缩略图未加载、场景不进资源列表）一并对齐，
否则"资源浏览器"这个名字与它的行为仍然不符。

## 2. 交互规则

| 操作 | 行为 |
| --- | --- |
| 单击资源文件 | 选中它，并立即显示预览（预览区就在资源面板内） |
| 再单击另一个 | 选中切换，预览同步切换 |
| 双击 | 脚本 → 脚本编辑器；场景 → 打开场景；其他 → 从资源创建实体（原有行为不变） |
| 右键 | 菜单不变；菜单不会清空选中，也不会清空预览 |
| 单击目录 | 只展开/折叠，不改变选中 |
| 关闭 / 切换项目 | 选中与预览清空（见 §6） |

预览区**位于资源面板内部**，不是独立面板：

* 可用宽度 ≥ `660` 逻辑像素 → 右侧分栏（默认 320 宽，可拖动，最小 220）；
* 否则 → 底部分栏（默认 250 高，可拖动）。

这样无论工作区怎么摆，用户都不会"把预览关掉之后再也找不到"。

## 3. 数据流与生命周期

```text
单击 → 界面状态.选中资源(路径)          （editor_ui，纯状态）
     → 预览请求{目标, 代次+1}
     → editor_app::asset_preview::处理预览请求
         ├─ 纯计算 计算预览(项目, 路径, 代次, 语言)   （读盘/解码/解析）
         └─ 落地 GPU/egui 资源（纹理 / 字体家族 / 模型相机）
     → 界面状态.资源预览 = 快照{代次, 阶段, 元数据, 画面}
     → editor_ui::asset_preview 只画"代次等于当前请求"的快照
```

# 关键性质

1. **只在选中变化时读盘**：面板每帧都画，但解码/解析只发生一次；
2. **代次防竞态**：快速点 A → B 时，迟到的 A 结果代次更小，不会覆盖 B；
3. **重复单击同一文件不重置**：不重复解码，也不把面板闪回"加载中"；
4. **身份是项目相对路径**（不是显示名）：`assets/a/hero.png` 与
   `assets/b/hero.png` 是两个不同的选中身份；
5. **不写源文件**：预览只读；失败只报告，不做任何"修复"。

## 4. 各类型的真实行为

| 类型 | 显示内容 | 实现 | 边界 |
| --- | --- | --- | --- |
| 图片（PNG/JPEG/WebP/BMP/GIF） | 真实位图，等比适配，透明图垫棋盘格；尺寸/格式/是否带 alpha | `image` 解码 → `Assets<Image>` → `EguiUserTextures` | 解码器只编了这 5 种；TGA/KTX2/Basis 归为"不支持" |
| 3D 模型（glTF/GLB） | 真实网格 + 材质渲染结果；可拖动旋转、滚轮缩放、重置视角；显示网格/材质数与包围盒 | 独立渲染层 3 + 独立 3D 相机 + `RenderTarget::Image` → egui 纹理；glTF 走 `AssetServer` + `WorldAssetRoot` | 只支持 `.gltf` / `.glb`；OBJ 不支持；骨骼动画不播放（静态姿态） |
| 音频（WAV/OGG） | 试听/停止；时长/采样率/声道/位深 | 复用 `audio_preview` 播放；WAV 头由本模块解析 | 只有 WAV 能读出元数据（OGG 不给时长，显示"未知"）；MP3/FLAC 不编译解码器，明确不可试听 |
| 字体（TTF/OTF） | 用**该字体自己的家族**渲染可编辑样例；家族名/字形数/缺字提示 | `ttf-parser` 解析 → egui 家族 `asset_preview_font` | 只取第 0 个字面（TTC 集合未展开）；变量字体按默认实例渲染 |
| 场景（`scenes/*.scene.ron`） | 实体数/根实体数/层级（名称+组件数，最多 200 条） | 直接读取并解析场景文档，**不接管**当前编辑会话 | 不提供 3D 缩略图（需要额外渲染世界，本轮不做）；不写回、不标脏 |
| 文本（`.ron`/`.json`/`.md`/`.rs`/`.wgsl`/`.toml`/`.txt`…） | 只读内容 + 行号 | 直接读文件 | 超过 512 KB 不读内容；最多显示 400 行 |
| 材质 / 着色器 | 按文本显示真实内容 | 同上 | 无语法高亮（按纯文本等宽显示） |
| 其他二进制 | **明确**的"不支持预览"+ 扩展名 | — | 不伪造画面 |
| 缺失 / 损坏 | "加载失败"+原因（含系统错误） | — | 与"不支持"区分开 |

## 5. 文件与调用点

| 位置 | 职责 |

## 6. 生命周期与失效处理

| 场景 | 行为 |
| --- | --- |
| 切换项目 / 关闭项目 | `清空资源预览`：清选中、清行几何、代次 +1、阶段回 `idle`；试听状态一并清空 |
| 文件被改名 | 若改的是当前预览目标，选中跟着改到新路径并重新加载 |
| 文件被删除 | 若删的是当前预览目标，清空选中；外部删文件时由 `监视选中资源变化` 重新加载并显示"文件不存在" |
| 外部覆盖文件 | mtime 或长度变化 → 自动重新加载（图片缓存键含 mtime+长度，不会命中旧图） |
| 快速切换 | 旧代次结果被丢弃 |
| 无项目 | 预览区显示"未选中资源"引导，不显示任何旧内容 |

## 7. 性能

* 预览只由**选中变化**驱动，不进入每帧路径；
* 图片按 `路径#mtime#长度` 缓存纹理，重复选中直接命中；
* 模型只在选中模型时创建相机与 512×512 渲染目标；离开模型预览时销毁；
* 文本/场景有大小与条数上限，避免一次读进超大文件；
* 同名不同目录不会互相污染缓存（键是完整项目相对路径）。

### 真实 GUI

脚本：`bash tools/asset_preview_acceptance.sh`（可重跑，9/9 通过）。
工具：`gui_probe drag`（`SendInput` 真实鼠标 + 应用内渲染目标回读）。

脚本里有三处**由真实失败换来的**约束，改动前请先读注释：

1. 每个会话必须在**独立进程**里启动（`bash -c ...`）。同一 bash 进程里连续
   spawn `gui_probe` 时，从第二个会话起 `received_pointer=false`：坐标与前台
   激活都正确，点击却没有到达客户区；
2. 每个会话用**独立配置目录**并控制窗口尺寸（默认 1280×800）。配置会持久化
   窗口位置，跨会话复用会让窗口越挪越偏，最后一部分移出屏幕；
3. 每次尝试前清掉项目里的恢复点。打开场景若引用了缺失资产会被标脏，
   退出时写恢复点，下次启动弹出"恢复自动保存"对话框盖住资源列表 ——
   这时点击落在对话框上，同样表现为 `received_pointer=false`。
   因此验收工程把场景引用的 `assets/tps/...` 资产也**一起复制**成副本，
   让工程自洽。

结果：`docs/验收证据/68_资源预览_验收报告.json`（9/9 通过）。

## 9. 已知缺口

1. **深层目录资源需要先展开**：资源浏览器默认只展开第一层，
   `assets/tps/environment/floor.png` 这类文件要两次点击才能到达。
   自动验收因此使用"工程自洽的临时验收项目"（资源全部是真实文件的副本，
   见 `.verify_r15/SOURCES.md`）；真实示例项目 `examples/3d_demo` 里的
   场景（`scenes/` 第一层）已在原项目上直接验证。
2. **场景预览没有 3D 缩略图**：只有层级与计数。缩略图需要额外的场景快照渲染，
   本轮不做（会与"不污染当前编辑场景"的约束纠缠）。
3. **模型材质不完整**：贴图与 PBR 由 Bevy glTF 加载器处理，但预览里没有
   材质参数检查器；蒙皮/动画不播放。
4. **音频元数据只有 WAV**；OGG 只能试听，不能报时长（不猜）。
5. **环境限制（非功能缺陷）**：本机沙箱子进程只在工作区根与
   `target/` 下可写，`%TEMP%` 与工作区子目录写不进去。依赖 `tempfile` 的
   既有测试因此需要
   `TEMP=<workspace>/target/tmp TMP=<workspace>/target/tmp` 才能跑；
   仍有三条既有测试在该环境下失败（它们要在临时目录里造 cargo 工程，
   而临时目录一旦落在仓库内就会被 cargo 判成"在工作区里但不在成员列表"）。
   这与本轮改动无关，机制与失败清单见 `docs/验收证据/69_资源预览_自动化测试日志.log`。
