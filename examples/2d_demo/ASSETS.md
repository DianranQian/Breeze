## 地形数据

| 文件 | 内容 |
| --- | --- |
| `assets/xiuxian/地形/qinglan_valley.terrain.ron` | 48×32 字符网格：`地表` + `覆盖` 两层 |

字符含义：

```text
地表：草=浅草  林=深草  水=海水  沙=沙滩  山=山地  丘=山丘  土=湿润的土
覆盖：. = 无     路 = 道路   田 = 耕地
```

它由 `tools/build_xiuxian_demo.py` 生成，不是手工拼接的图片。
渲染侧的字符映射在 `crates/editor_app/src/tile_terrain.rs`，
两边改字符时必须同步（有单元测试守着映射）。

## 实际验证方式

本示例不再依赖"截图看起来对不对"来验收。自动化侧检查：

- `tile_terrain::测试::示例地形能烘焙出完整纹理`：用真实数据与图集烘焙
  3072×2048 纹理，断言 48×32 格、**零透明像素**；
- `示例项目::二维示例使用程序化瓦片地形`：场景里必须是 `TileTerrain`，
  地形数据不是图片；
- `示例项目::素材目录没有孤儿文件`：每个 PNG 要么被场景引用，要么属于
  地形图集目录。
