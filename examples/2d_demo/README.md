# 林间营地 · 2D 示例项目

一个可直接用 **Bevy Studio** 打开的俯视角营地场景，用来体验二维编辑的完整闭环：
场景树层级 → 选中 → Inspector 改属性/变换 → 视口观察 → 保存 → 重新打开。

## 怎么打开

方式一（菜单，推荐）：

1. 启动 `bevy-studio`；
2. 顶部菜单「项目 → 打开 2D 示例项目」；
3. 编辑器会自动打开项目并切到 **2D** 模式，视口中央是营地场景。

方式二（命令行 / 自动化验收）：

```powershell
$env:BEVY_STUDIO_OPEN_PROJECT = "<仓库路径>\examples\2d_demo"
$env:BEVY_STUDIO_MODE = "2d"
.\bevy-studio.exe
```

方式三：直接用「项目 → 打开项目…」选择本目录（含 `project.ron` 的目录）。

> 项目内所有贴图路径都是**项目相对路径**（`assets/2d_demo/*.png`），
> 整个目录可以复制到任意机器打开，不依赖本机的绝对路径。

## 场景里有什么

| 层级 | 内容 |
| --- | --- |
| `林间营地`（根） | 逻辑根节点 |
| └ `地面` | 15 块地砖：5×3 草地，中间一列为土路（z=-20，在最底层） |
| └ `装饰` | 红枫、金枫、石碑、祭坛、远树（z=10） |
| └ `敌人` | 哥布林斥候、兽人战士、狗头人（z=0） |
| └ `道具` | 金币堆、蓝色药水、黑色药水（z=5） |
| └ `玩家` | 主角精灵（z=20，最上层） |

共 32 个实体，名称稳定（自动化验收依赖这些名字，改名请同步更新测试）。

## 建议体验步骤

1. **看层级**：在场景树展开 `林间营地`，注意四个分组与各自的子对象；
2. **选中**：点 `玩家`，Inspector 出现变换与 Sprite 属性（贴图、颜色、自定义尺寸、翻转）；
3. **改属性**：把「自定义尺寸」改成 `160, 160`，视口里的角色立刻变大；
4. **改变换**：把位置 X 从 `0` 改成 `120`，角色向右移动；
5. **切模式**：点顶部 `3D`，用右键拖动旋转视角观察同一份数据的空间关系，再切回 `2D`（选择与数据都不会丢）；
6. **保存**：`Ctrl+S`（或工具栏保存按钮）；
7. **重开**：关闭项目后重新打开（或重启编辑器），确认第 3、4 步的修改仍在；
8. **换主题/语言**：`窗口 → 主题`、`窗口 → 界面语言`，确认布局与场景都不受影响。

- 精灵来自 **Dungeon Crawl Stone Soup** 的 32×32 图块集（CC0 / 公共领域），
  原始包：<https://opengameart.org/content/dungeon-crawl-32x32-tiles>（`crawl-tiles Oct-5-2010.zip`）；
- 本项目只取用了 14 个文件，清单与用途见 [`ASSETS.md`](./ASSETS.md)；
- 许可证原文见 [`assets/DCSS_TILESET_LICENSE.txt`](./assets/DCSS_TILESET_LICENSE.txt)（CC0，无需署名，此处保留来源记录）。

## 已知限制

- 编辑器当前是**精灵四边形**渲染：不支持瓦片图集切分、动画、骨骼；
- 没有物理/寻路/玩法系统，这是一个**编辑与展示**用场景；
- 3D 模式是"二维场景的三维观察与定位"，不是三维建模。

## 重新生成

场景与项目清单由生成器产生（避免手写 RON 出错）：

```powershell
cargo run -p editor_core --example 生成演示项目
```

生成器只重写 `project.ron` 与 `scenes/`，**不会删除 assets**。
