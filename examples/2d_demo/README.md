# 青岚山谷 · 2D 示例项目

以本地项目 **《修仙冒险游戏》**（`修仙冒险游戏/`）的真实地形与主角素材制作的俯视角场景，
用来体验 微风 的二维编辑闭环：场景树 → 选中 → Inspector → 视口 → 保存 → 重新打开。

## 怎么打开

1. 启动 `bevy-studio`；
2. 菜单「项目 → 打开 2D 示例项目」（或「项目 → 打开项目…」选择本目录）；
3. 编辑器自动进入 **2D** 模式，视口显示青岚山谷的草地、山道、崖壁、水潭与主角。

命令行 / 自动化验收：

```powershell
$env:BEVY_STUDIO_OPEN_PROJECT = "<仓库路径>\examples\2d_demo"
$env:BEVY_STUDIO_MODE = "2d"
.\bevy-studio.exe
```

## 场景组成（26 实体）

| 层级 | 内容 |
| --- | --- |
| `青岚山谷`（根） | 逻辑根 |
| └ `地面` | 15 块地砖：5×3 布局，中央一列为山道，其余为灵草地（z=-20） |
| └ `景观` | 北崖、东崖、碧水潭、白沙岸、灵田（z=10） |
| └ `人物` | 主角（idle 帧）、同门师姐（walk 帧），z=20/18 |

名称稳定，自动化验收依赖这些名字。

## 建议体验步骤

1. 展开 `青岚山谷`，观察四个分组与 26 个对象；
2. 选中 `主角`，Inspector 显示变换与 Sprite 属性（贴图、颜色、自定义尺寸、翻转）；
3. 把「自定义尺寸」改成 `192, 192`，视口里的主角变大；
4. 把位置 X 改成 `120`，主角向右移动；
5. 切到 `3D` 观察同一份数据的空间关系，再切回 `2D`；
6. `Ctrl+S` 保存，关闭后重新打开，确认修改仍在；
7. 切换深色/浅色/高对比度主题与中英文，确认场景与布局不受影响。

## 素材来源（详见 [`ASSETS.md`](./ASSETS.md)）

- 地形：源项目 `assets/tilesets/` 下的 **64×64 单格 PNG**（透明边缘可直接叠放），
  按原样复制，未做格式转换；
- 主角：`assets/sprites/protagonist.png` 是 **2112×64 的图集**（33 帧 × 64px）。
  当前编辑器没有图集切分能力，因此用一次性脚本按 64px 切出第 0 帧与第 7 帧，
  存为 `protagonist_idle.png` / `protagonist_walk.png`；**源图未被修改**。
- 这两张图只是**静态帧**，示例不代表已支持动画播放。

## 已知限制

- 无瓦片地图编辑：地形是独立精灵对象，不能刷子绘制或自动拼接；
- 无动画系统：不会播放主角行走序列；
- 无碰撞/寻路/玩法逻辑；
- 图集切分目前靠离线脚本，不是编辑器功能（路线图里属于资产管线工作）。

## 保存与验收

`Ctrl+S` 写入 `scenes/qinglan_valley.scene.ron`；重新打开项目会自动载入启动场景。
场景文件只保存**项目相对路径**，整个目录可复制到其他机器打开。
