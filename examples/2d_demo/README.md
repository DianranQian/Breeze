# 青岚山谷 · 2D 程序化瓦片示例

以本地项目 **《修仙冒险游戏》** 的真实素材与渲染规格制作的俯视角场景。

这个示例要证明的不是"能摆几张图"，而是：

> **地面不是一张 PNG，而是加载时按双网格自动瓦片规则算出来的。**

- 地形数据：`assets/xiuxian/地形/qinglan_valley.terrain.ron`（48×32 个字符）
- 瓦片图集：`assets/xiuxian/瓦片/`（原项目 `assets/art/瓦片/` 的 10 张四角图集 + 1 张变体表，原样复制）
- 渲染实现：`crates/editor_app/src/tile_terrain.rs`

## 怎么打开

1. 启动 `bevy-studio`；
2. 菜单「项目 → 打开 2D 示例项目」（或「项目 → 打开项目…」选择本目录）；
3. 编辑器自动进入 **2D** 模式，并把视口框到整张地图。

命令行 / 自动化验收：

```powershell
$env:BEVY_STUDIO_OPEN_PROJECT = "<仓库路径>\examples\2d_demo"
$env:BEVY_STUDIO_MODE = "2d"
.\bevy-studio.exe
```

## 地面是怎么画出来的

```text
字符网格（草/林/水/沙/山/丘/土 + 路/田）
  ──► 逻辑格材质
  ──► 每张视觉瓦片四角掩码（TL/TR/BR/BL → 8/4/1/2）
  ──► 图集按 POS 取 16px 瓦片（整格 35% 概率抽手绘变体）
  ──► 按 DRAW_SURFACES 分层合成（后画的材质抢像素）
  ──► 最近邻放大到 64px/格
```

这套规则逐条来自原项目：

| 规则 | 原项目出处 |
| --- | --- |
| 图集索引乱序 | `src/mapgen/atlas.rs` → `POS` |
| 四角位权 | `CORNER_BIT = [8,4,1,2]` |
| 地表绘制顺序 | `DRAW_SURFACES` |
| 整格变体与 0.35 概率 | `瓦片地图变体_丰富地图细节.png` / `balance.ron` |
| 道路/耕地在最后 | `bake.rs` → `Layer::ALL` |

改 `.terrain.ron` 里任意一个字符，保存后回到编辑器，地面会按新数据重烘
（缓存用文件 mtime 判断）。

## 场景组成

| 层级 | 内容 |
| --- | --- |
| `青岚山谷`（根） | 逻辑根 |
| └ `地形` | `青岚山谷地形`：**一个** `TileTerrain` 实体，48×32 格，显示 3072×2048 |
| └ `村落` | 东屋 / 西屋 / 南屋 / 谷仓 / 水井 / 木牌 |
| └ `植被` | 12 棵古樟、4 棵松树、4 丛灌木 |
| └ `山石` | 5 块山石 |
| └ `人物` | 主角、同门师姐、采药人、村民 |

共 46 个实体。名称稳定，自动化验收依赖这些名字。

## 建议体验步骤

1. 选中 `青岚山谷地形`，看 Inspector：地形文件、图集目录、显示尺寸、每格像素、变体概率；
2. 把「每格像素」从 64 改成 32，地形纹理分辨率降低（预览重新烘焙）；
3. 选中 `主角`，把「自定义尺寸」改成 `192, 192`，视口里的主角变大；
4. 把位置 X 改成 `120`，主角向右移动；
5. 切到 `3D` 观察同一份数据的空间关系，再切回 `2D`；
6. `Ctrl+S` 保存，关闭后重新打开，确认修改仍在；
7. 用文本编辑器改 `.terrain.ron` 里一个 `草` 为 `水`，回到编辑器观察那一格变成水面。

## 素材来源（详见 [`ASSETS.md`](./ASSETS.md)）

- 地形图集：源项目 `assets/art/瓦片/` 下的 64×64 四角图集，**原样复制**；
- 地形数据：本仓库 `tools/build_xiuxian_demo.py` 生成，是字符网格，不是图片；
- 主角/同门师姐/采药人/村民：源项目 `assets/sprites/protagonist.png`（2112×64，33 帧）的
  第 0/4/20/10 帧，按 64px 切出后 ×2.5 显示；**源图未被修改**；
- 道具（茅屋/谷仓/水井/树/岩石/木牌）：按源项目 `texture.rs::物件外观` 的尺寸口径
  （树 24px、茅屋 24px、粮仓 32px）补的像素画，配色取自同一套调色板。

## 已知限制

- 没有地形刷子/瓦片绘制 UI：地形数据目前是文本编辑；
- `地形文件` / `图集目录` 是文本字段：在资源浏览器里重命名文件不会自动同步，需手动改路径；
- 不播放角色动画：四张静态帧；
- 没有碰撞/寻路/玩法逻辑；
- 山崖岩壁层未接入：原项目的岩壁依赖 16×32 塔块与连续台地，直接套山丘掩码会碎成红点；
  示例用岩石道具表现山脚；
- 运行时世界只持有地形/几何体数据组件，暂未把程序化地面渲染进运行时（本示例演示编辑器预览）。

## 保存与验收

`Ctrl+S` 写入 `scenes/qinglan_valley.scene.ron`；重新打开项目会自动载入启动场景。
场景文件只保存**项目相对路径**，整个目录可复制到其他机器打开。

## 重新生成

```powershell
# 1) 复制原项目图集、生成地形字符网格与道具（不烘焙地面）
python tools/build_xiuxian_demo.py `
    --source "C:\Spaces\Share\10_Code\10_Bevy\修仙冒险游戏\assets" `
    --out examples/2d_demo/assets/xiuxian `
    --layout examples/2d_demo/layout.json

# 2) 通过编辑器 API 生成场景（只重写 project.ron 与 scenes/）
cargo run -p editor_core --example generate_demo_project
```
