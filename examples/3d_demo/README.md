# TPS 竞技场 · 3D 示例项目

以本地 Bevy 项目 **TPS Arena**（`tps-demo/tps_arena`）的真实资产与场景设计为基础，
用 微风 的 3D 模式打开、观察和编辑的示例。

## 怎么打开

1. 启动 `bevy-studio`；
2. 菜单「项目 → 打开 3D 示例项目」（或「项目 → 打开项目…」选择本目录）；
3. 编辑器自动进入 **3D** 模式，视口显示混凝土场地、带窗围墙、三名角色与掩体道具。

命令行 / 自动化验收：

```powershell
$env:BEVY_STUDIO_OPEN_PROJECT = "<仓库路径>\examples\3d_demo"
$env:BEVY_STUDIO_MODE = "3d"
.\bevy-studio.exe
```

## 场景组成

| 层级 | 内容 | 说明 |
| --- | --- | --- |
| `TPS 竞技场`（根） | 逻辑根 | — |
| └ `场地` | 9 块场地砖（8×8 世界单位，绕 X 轴 −90° 平铺于 y=0） | 贴图来自 TPS Arena `environment/floor.png` |
| └ `掩体与建筑` | 北侧围墙、西侧围墙 | `environment/wall.png`，侧墙绕 Y 轴 90° |
| └ `角色` | 玩家士兵、近战敌人、远程敌人 | **真实 glTF 网格模型**，位置各不相同 |
| └ `道具` | 长货柜、木箱、爆炸桶、路障、锥桶、沙袋 | **真实 glTF 网格模型** |

共 25 个实体。模型实体的 `模型` 字段保存项目相对路径（`assets/tps/...gltf`），
预览通过 Bevy 的 glTF 场景加载器实例化，位置/旋转/缩放来自场景文档的变换。

## 当前 3D 编辑器实际支持

- 透视 `Camera3d`、轨道相机（右键/中键旋转、Shift 平移、滚轮缩放）；
- 地面网格、X/Y/Z 三轴、实体锚点与选中框；
- 左键屏幕空间拾取（14px 阈值），Inspector 显示选中对象；
- Inspector 编辑位置 X/Y/Z、旋转（角度 ↔ 四元数）、缩放 X/Y/Z；
- 模式切换（2D/3D/代码/运行/资源）共享同一份场景文档；
- 保存 / 重新打开（`Ctrl+S`，场景 RON）。

## 已知限制（不要误解）

- 模型是**静态**加载：不播放 glTF 动画、不做骨骼驱动；
- 不支持在编辑器内更换模型材质/贴图，也不能导入新的 glTF 文件（`模型` 字段可手填路径，
  但资源选择器目前只列图片类型）；
- 拾取按屏幕距离命中模型锚点，不是对实际网格做射线求交；
- 没有视口 gizmo，三维变换在 Inspector 中编辑；
- 原 TPS Arena 的玩法（射击、敌人 AI、相机跟随、音频）**不在示例中**。

## 相对原项目的简化

- 只取一个有代表性的竞技场区域，不是整张地图；
- 场景中不含 HUD、音效、粒子、爆炸效果；
- 角色模型使用默认姿态（不含动画状态）。

## 保存与验收

1. 选中「玩家士兵」，把 Y 改为 `1.5`，视口里角色应升起；
2. `Ctrl+S` 保存；
3. 关闭项目后重新打开（或重启编辑器），确认修改仍在；
4. 切到 2D / 代码模式再切回 3D，确认模型与变换未丢失。

## 重新生成

