# TPS 竞技场 · 3D 程序化几何示例

以本地 Bevy 项目 **TPS Arena**（`tps-demo/tps_arena`）的关卡与真实资产为基础，
用编辑器的 **`Primitive3d` 受光几何体** + glTF 道具复刻的完整竞技场。

这个示例要证明的不是"能显示几个模型"，而是：

> **地面和围墙是实心几何体 + 受光 PBR 材质，不是 unlit 贴图纸片。**

- 地面：48×48×0.6 长方体，`floor.png` 6×6 UV 重复；
- 围墙：四面 48×8×0.6 长方体，`wall.png` 6×1 UV 重复；
- 掩体：23 件真实 glTF，位置逐条对应原项目 `src/plugins/level.rs::掩体布局`；
- 光照：方向光 + 环境光，**阴影开启**。

## 怎么打开

1. 启动 `bevy-studio`；
2. 菜单「项目 → 打开 3D 示例项目」（或「项目 → 打开项目…」选择本目录）；
3. 编辑器自动进入 **3D** 模式。

命令行 / 自动化验收：

```powershell
$env:BEVY_STUDIO_OPEN_PROJECT = "<仓库路径>\examples\3d_demo"
$env:BEVY_STUDIO_MODE = "3d"
.\bevy-studio.exe
```

默认镜头对着中央主掩体与双方角色（游戏视角）。想看整个 48×48 竞技场，
点工具栏的「适应窗口」；想看某个掩体，选中后点「聚焦选中」。

## 场景组成（36 个实体）

| 层级 | 内容 | 说明 |
| --- | --- | --- |
| `TPS 竞技场`（根） | 逻辑根 | — |
| └ `场地` | `竞技场地板` + 北/南/东/西墙 | 5 个 `Primitive3d`，受光、UV 重复 |
| └ `掩体与建筑` | 23 件来自原项目 `掩体布局` 的 glTF | 四角货柜、中央长货柜、沙袋墙、木箱、油桶、铁马、交通锥 |
| └ `角色` | 玩家士兵、近战敌人、远程敌人、重装敌人 | 真实 glTF 模型 |

### 掩体清单（与原项目一致）

| 组 | 数量 | 位置 |
| --- | --- | --- |
| 货柜 | 5 | 四角 ±9/±7 + 中央 (0,0)，其中两件绕 Y 轴 90° |
| 沙袋墙 | 2 | (±14, 0)，绕 Y 轴 90° |
| 木箱 | 6 | 四角 ±19/±11 + 南侧 ±9/-19 |
| 油桶 | 4 | 四角 ±17/±17 |

| 交通锥 | 4 | (±5, ±14) |

## 渲染方式（为什么不是贴图地板）

| 组件字段 | 值 | 作用 |
| --- | --- | --- |
| `形状` | `Cuboid` | 生成真正的 `Mesh3d`，有厚度 |
| `尺寸` | (48, 0.6, 48) / (48, 8, 0.6) | 封闭竞技场 |
| `贴图` | `environment/floor.png` / `wall.png` | 256×256 原始纹理 |
| `贴图重复` | (6, 6) / (6, 1) | 地面 1m 网格、墙面 2m 板 |
| `受光` | true | PBR 材质接收方向光与阴影 |
| `双面` | false | 封闭长方体的背面剔除 |

渲染实现在 `crates/editor_app/src/preview.rs`（`Primitive3d` 分支），
模型仍是 Bevy 的 glTF 场景加载器。

## 建议体验步骤

1. 选中 `竞技场地板`，看 Inspector 里的形状/尺寸/贴图重复/受光；
2. 把「贴图重复」从 6,6 改成 3,3，地面网格变大；
3. 把「受光」关掉，地面变成 unlit（对比受光与阴影的差别）；
4. 选中 `长货柜·中央`，把位置 X 改成 `3`，主掩体移动；
5. 点「适应窗口」看完整竞技场，再点「聚焦选中」回到近景；
6. `Ctrl+S` 保存；关闭后重新打开，确认修改仍在。

## 重新生成

```powershell
cargo run -p editor_core --example generate_demo_project
```

生成器只重写 `project.ron` 与 `scenes/`，不会删除 `assets/`。

## 已知限制（不要误解）

- 模型是**静态**加载：不播放 glTF 动画、不做骨骼驱动；
- 没有射击/敌人 AI/HUD/音效等玩法；
- 拾取按屏幕距离命中实体锚点，不是对网格做射线求交；
- 视口没有 3D gizmo，三维变换在 Inspector 中编辑；
- 默认镜头是近景；想一眼看全 48×48 需要点「适应窗口」。
