# 浮空圣所 · 3D 示例项目

一个用 **Bevy Studio 3D 模式**观察与编辑的空间场景：透视相机、轨道控制、
地面网格、X/Y/Z 三轴、屏幕拾取与三维变换，都能在真实数据上验证。

> **能力边界（务必先读）**：当前 3D 模式是"二维场景的三维观察与定位"。
> 渲染出来的是**带贴图的四边形**（`Mesh3d` + unlit 材质），不是网格模型、
> 也没有材质编辑器与灯光编辑。本项目如实使用这套能力：地面砖块通过
> 旋转四元数平铺在 y=0 平面，角色/道具是竖直的贴图四边形，靠位置与缩放
> 形成空间层次。

## 怎么打开

1. 启动 `bevy-studio`；
2. 菜单「项目 → 打开 3D 示例项目」→ 自动进入 **3D** 模式；
3. 视口显示 3×3 棋格地基、中央祭坛、两棵树、石碑、三个角色与两个悬浮拾取物。

命令行 / 自动化验收：

```powershell
$env:BEVY_STUDIO_OPEN_PROJECT = "<仓库路径>\examples\3d_demo"
$env:BEVY_STUDIO_MODE = "3d"
.\bevy-studio.exe
```

## 场景结构与空间布局

| 层级 | 内容 | 位置特点 |
| --- | --- | --- |
| `浮空圣所`（根） | 逻辑根 | — |
| └ `地基` | 9 块地砖（两种贴图交替） | y=0 平面，绕 X 轴 −90° 平放，2×2 世界单位 |
| └ `建筑` | 中心祭坛、左侧古树、右侧古树、后方石碑 | 不同 x/z 深度，尺度 2.0~3.0 |
| └ `单位` | 主角 (0, 0.9, 1.8)、哥布林 (−2.6, 0.7, −0.6)、兽人 (2.8, 0.8, 2.6) | 三个不同深度 |
| └ `拾取物` | 悬浮金币（y=1.8）、悬浮药水（y=2.1） | 检验 Y 轴高度 |

共 23 个实体；名称稳定（验收依赖这些名字）。

## 建议体验步骤

1. 进入 3D 模式，确认地面网格与红(X)/绿(Y)/蓝(Z) 三轴方向；
2. **右键拖动**旋转视角，**Shift+拖动**平移，**滚轮**缩放；
3. 点击不同对象：选中框应落在对象脚下锚点上，Inspector 显示该对象；
4. 在 Inspector 修改 **X/Y/Z 位置**、**旋转角度**、**缩放**，观察视口同步变化；
5. 点 `浮空金币`，把 Y 改成 `3.0`，确认它升到空中（Y 轴方向正确）；
6. 切到 `2D` 或 `代码` 模式再切回 `3D`：对象与变换保持不变；
7. `Ctrl+S` 保存 → 重启 → 重新打开项目，确认三维变换仍在。

## 已知限制

- 只有贴图四边形，无网格模型/法线/材质/灯光编辑；
- 拾取是**屏幕空间最近点**，不是射线求交（对象没有厚度）；
- 无视口内 gizmo：三维变换目前在 Inspector 中编辑（gizmo 属于下一阶段 M2）。
